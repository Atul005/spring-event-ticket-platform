# Event Tickets Platform

A full-stack platform for managing and selling event tickets, built with **Java Spring Boot backend**, **React/TypeScript frontend**, and **Dockerized services** including PostgreSQL, Keycloak, and Adonis.  

## Features

### Backend
- Built with **Spring Boot** and **Java**
- REST APIs for:
  - Event management
  - Ticket creation & validation
  - User management
- **Authentication & Authorization** handled by Keycloak
- Data stored in **PostgreSQL**
- Fully containerized with **Docker**

### Frontend
Taken from DevTiro dicrod server.
- Built with **React** and **TypeScript**
- Pages include:
  - Event listings
  - Ticket purchase
  - Organizer dashboard
- Connects to backend APIs
- Uses Discord server for development notifications

### Docker Services
- **PostgreSQL** for database
- **Keycloak** for auth management
- Optional **Adonis** for additional microservices
